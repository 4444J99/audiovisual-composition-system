# Workspace layout 2.0.0

Adopted locally on 2026-10-12 on `distill/phase-1`; the published branch is in
[PR 2](https://github.com/4444J99/audiovisual-composition-system/pull/2), open for review.

## Before and after

Contract 1.0.0 described a non-Git workspace with coordination under `system/`, and required `--workspace ..` for links. The distillation branch already flattened the coordination Git checkout into the workspace root, removed the eleven repository/component/archive READMEs and reduced the editor workspace to one folder, but retained the old validator and CI test paths.

Contract 2.0.0 makes that existing flat root authoritative with `layout: workspace-root`. `root_entries` declares authored, generated and administrative top-level entries. Local bindings and `preserved_root_files` declare ignored source material. The generator restores all eleven records and the five editor folders, and owns the marked sources block at the end of `.gitignore`. No source checkout, remote, history or original archive filename moves or changes. Unversioned `engine/` and root `tests/` stay outside this repository's tracked files.

The former empty `backwards-up-hill` source directory is absent. Its project ID and aliases remain; its manifest binding is explicitly unresolved rather than inventing a replacement. Four pre-existing loose Markdown files remain in place, declared and ignored: `HANDOFF_AMBISONIC_INTEGRATION.md`, `PROJECT.md`, `TEST_INFRA.md`, and `TEST_READY.md`. TMB's dirty state and Danse's remote-authority decision remain open.

## Consumers and checks

- `tools/workspace_layout.py`: `render`, `check`, `plan`, `apply` and read-only `status` operate from the Git root without `--workspace`. `check` requires current generated files, declared top-level entries, existing ignored sources, source repository `.git` markers, safe tracked paths and all navigation links. Apply preflights collisions before creating any links. Source targets cannot resolve outside the root; the existing sibling legacy alias is the sole external navigation destination.
- `audiovisual-composition-system.code-workspace`: generated Workspace, Projects, Repositories, Components and Archives folders; symlink searching disabled. No editor settings are authored separately.
- `.github/workflows/verify.yml`: Python and Node tests now use `tools/tests/`. CI explicitly invokes `check --catalog-only` because private and archival source checkouts are not shipped. This still checks generated views, declarations, ignore rules and tracked paths; any repository source present must contain `.git`. It does not certify absent local sources or links.
- `tools/verify_tmb_composition.cjs`: preserved without edits. It lives at the same root-relative tools path on the flattened branch; its six acceptance-guard tests pass at the new CI test path. No real-media or device acceptance is claimed for this layout migration.
- Manifest `membership_source`: remains `docs/sources/ace-project-membership-2026-10-10.json`. All fifteen project IDs, Page IDs, aliases, numeric GitHub IDs and native identities are retained and checked against the observed membership.
- `status`: reports HEAD, branch (or detached state), uncommitted file count, worktree count and cached upstream ahead/behind. Missing and unversioned sources are explicit; null counts mean no upstream. It does not fetch or change source Git state.

## Validation evidence

TMB retains 37 changes and eight worktrees. Thirteen Python safety tests and six Node guard tests pass. Strict local check and clean-checkout catalog validation pass. ## Review corrections, 2026-10-12

Archive bindings now declare `version_control` explicitly. Git-backed archives
and repository bindings must retain a valid `.git` marker and their own Git root;
catalog-only checks permit absent workstation sources but validate any present.
Every planned internal navigation link must be ignored, including destinations
not yet created in a catalog-only checkout. Removing an effective ignore rule or
negating it fails validation. Integration-report links now resolve to the relocated
receipts under `docs/evidence/`. Historical receipts remain unchanged.

## Rollback

Revert the layout 2.0.0 commit on a review branch to restore the preceding distillation metadata. This does not move or alter sources. The preceding flat branch has an incompatible 1.0.0 local-link validator and CI test paths; reverting does not repair that older mismatch. Leave ignored navigation links in place until a separately reviewed link-only cleanup; never remove source directories to make a rollback check pass. To re-adopt, restore the 2.0.0 commit, run `render`, inspect `plan`, run `apply`, then `check` and the tools tests. Keep the existing checkout and source worktrees retained.
